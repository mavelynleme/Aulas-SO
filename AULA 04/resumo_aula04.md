# 📚 Pesquisa: Sistemas Operacionais Baseados em Outros Sistemas

## 🖥️ Introdução

No desenvolvimento de sistemas operacionais, é muito comum que novos sistemas não sejam criados completamente do zero. Em vez disso, muitos desenvolvedores utilizam como base sistemas já existentes, reaproveitando componentes importantes como o **kernel**, a **arquitetura**, a **estrutura de arquivos** ou partes da infraestrutura do sistema.

Essa prática traz diversas vantagens:

- 🔧 Redução do tempo de desenvolvimento  
- 🛡️ Maior estabilidade e segurança  
- 🔄 Reutilização de tecnologias já consolidadas  
- 🌎 Suporte de comunidades e atualizações constantes  

Conforme apresentado em aula, muitos dispositivos utilizam sistemas operacionais derivados de outros. Por exemplo, o **Raspberry Pi OS** é baseado no **Debian**, enquanto o sistema operacional do **PlayStation 4 (Orbis OS)** possui base no **FreeBSD**.

Nesta pesquisa foram identificados **cinco sistemas operacionais que utilizam como base outros sistemas**, analisando suas principais diferenças e finalidades.

---

# 🔎 Sistemas Operacionais Identificados

A seguir estão alguns exemplos de sistemas operacionais que foram desenvolvidos a partir de outros sistemas ou que utilizam seu kernel ou estrutura.

---

## 🐧 Ubuntu
**Sistema base:** Debian (Linux)

O Ubuntu é uma das distribuições Linux mais populares do mundo. Ele foi desenvolvido a partir do Debian, mantendo o mesmo kernel Linux e parte da estrutura do sistema.

### Principais características
- Interface amigável para usuários iniciantes  
- Atualizações frequentes  
- Grande comunidade de suporte  
- Utilizado em computadores pessoais e servidores  

---

## 🍓 Raspberry Pi OS
**Sistema base:** Debian (Linux)

O Raspberry Pi OS é o sistema operacional oficial para computadores **Raspberry Pi**. Ele é uma adaptação do Debian, otimizada especificamente para funcionar no hardware desses dispositivos.

### Principais características
- Otimizado para placas Raspberry Pi  
- Baixo consumo de recursos  
- Ferramentas educacionais integradas  
- Muito utilizado em projetos de robótica e IoT  

---

## 🎮 Orbis OS
**Sistema base:** FreeBSD

O Orbis OS é o sistema operacional utilizado no **PlayStation 4**. Ele é baseado no FreeBSD, um sistema Unix-like conhecido pela sua estabilidade e segurança.

### Principais características
- Adaptado para hardware de consoles  
- Otimizado para jogos e multimídia  
- Interface própria da Sony  
- Alto desempenho gráfico  

---

## 🍏 macOS
**Sistema base:** BSD / NeXTSTEP

O macOS é o sistema operacional utilizado nos computadores da Apple. Ele possui base em tecnologias Unix derivadas do BSD e do antigo sistema NeXTSTEP.

### Principais características
- Interface gráfica exclusiva da Apple  
- Forte integração com hardware da empresa  
- Sistema Unix certificado  
- Alta estabilidade e segurança  

---

## 🤖 Android
**Sistema base:** Linux

O Android é o sistema operacional mais utilizado em smartphones no mundo. Ele utiliza o **kernel Linux**, porém com diversas modificações para dispositivos móveis.

### Principais características
- Sistema aberto e altamente customizável  
- Desenvolvido principalmente pelo Google  
- Adaptado para telas sensíveis ao toque  
- Grande ecossistema de aplicativos

# 📈 Análise Comparativa

Observando os sistemas apresentados, é possível perceber que muitos deles utilizam como base **sistemas Unix ou Linux**, pois esses sistemas são conhecidos pela sua estabilidade, segurança e flexibilidade.

Outra característica importante é que cada sistema adapta a base original para atender necessidades específicas:

- 📱 **Android** foi adaptado para dispositivos móveis  
- 🎮 **Orbis OS** foi otimizado para jogos  
- 🍓 **Raspberry Pi OS** foi modificado para placas educacionais  
- 🖥️ **Ubuntu** foi projetado para facilitar o uso do Linux em desktops  

Isso demonstra como um mesmo núcleo tecnológico pode ser reutilizado em diferentes tipos de dispositivos.

---

# ✅ Conclusão

O reaproveitamento de sistemas operacionais existentes é uma estratégia amplamente utilizada na área da computação. Em vez de desenvolver um sistema completamente novo, muitas empresas e organizações utilizam **kernels e arquiteturas já consolidadas**, realizando adaptações para atender necessidades específicas.

Essa abordagem permite:

- maior eficiência no desenvolvimento  
- redução de custos  
- maior estabilidade do sistema  
- compatibilidade com tecnologias existentes  

Os exemplos apresentados mostram que sistemas operacionais utilizados no dia a dia — como **Android, macOS e Ubuntu** — possuem suas origens em sistemas anteriores, evidenciando a importância da reutilização de tecnologias no avanço da computação.
